# Projet-SAS

Programme C de gestion d’étudiants en console. Le menu permet de rechercher, trier et analyser les notes par département.

[Menu et structures de données](https://github.com/Abdelhakim-Baalla/Projet-SAS/blob/main/Projet/projet.c)

Compiler avec `cc Projet/projet.c -o gestion-etudiants`, puis lancer `./gestion-etudiants` dans un terminal.
